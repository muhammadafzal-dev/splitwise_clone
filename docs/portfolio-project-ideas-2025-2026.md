# Portfolio Project Ideas 2025-2026

**Purpose:** High-value portfolio projects aligned with current market demand for AI/ML and full-stack roles.
**Last Updated:** March 2025

---

## Top Tier Projects (Maximum Career Signal)

### Tier 1 - AI/ML Roles

1. **Production RAG Document Intelligence System**
   - Ingest PDFs, vector DB (pgvector/Qdrant), hybrid search, LangSmith observability
   - Why: Every enterprise wants this; demonstrates production AI skills

2. **Autonomous Multi-Agent Research Assistant**
   - LangGraph/CrewAI, tool use, cost tracking
   - Why: Agentic AI is the hottest area in the industry

3. **AI Mock Interview Platform**
   - Whisper transcription, LLM feedback, WebRTC, full stack
   - Why: High consumer appeal, demonstrates breadth of skills

4. **MCP Server for a Business Domain**
   - Model Context Protocol (Anthropic standard, adopted by OpenAI/Google/Microsoft)
   - Why: Almost nobody has this in their portfolio — huge enterprise demand

### Tier 2 - Full Stack Roles

5. Real-time collaboration tool with AI co-pilot (Yjs + WebSockets + LLM)
6. Plain-language workflow automation builder (Zapier-lite + LLM intent parsing)
7. AI-powered Code Review GitHub App

### Tier 3 - Niche / Differentiated

8. **WCAG Accessibility Scanner SaaS** — 98% of websites fail, only ~4 competitors
9. **Field Service Scheduling for Trades** — HVAC/plumbing market severely underserved
10. **Nonprofit Donor CRM** — $29/month, 1.5M nonprofits still use spreadsheets
